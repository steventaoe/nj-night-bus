# 南京夜间公交全网运行模拟 · Nanjing Night Bus Network

在真实地图上绘制南京全部夜间公交线路，并按真实时刻表模拟每一班车的运行。

**在线演示：<https://steventaoe.github.io/nj-night-bus/>**（单文件网页，无需安装，手机/桌面浏览器均可）

## 这是什么

南京在深夜地铁停运后，仍有一张覆盖主城、江北、江宁乃至溧水、高淳的夜间公交网络在运转。本项目把这张网络完整地搬到真实地图上，并让它"活"起来：

- **43 条线路 / 86 个方向 / 1080 个站点**：Y 系列夜间线（Y1–Y45 中现存的 35 条）、2 条地铁末班守时公交，以及溧水（Y1/Y2/Y5）、高淳（801/802/803）的夜间线路。两个方向的站点分别采集，单向站如实呈现。
- **关于 502 路**：502 路为白天常规线，**不计入本模拟**；其夜间服务由守时公交1号线（SS1）承担。采集脚本虽检索过 502 路，但构建线网时已作为白天线剔除。
- **626 个夜班班次**：每条线路每个方向的发车时刻表均来自百度地图收录的官方固定时刻表。
- **模拟时间窗 15:00 → 次日 07:40**：从首班夜公交发车，到最后一班车约 07:22 抵达终点收车，窗口留有余量至 07:40；全程可播放、可拖动、可手动输入时刻跳转。峰值时刻全网同时有 **90 辆车**在运行。

数据截至 **2026-11-20**（飞站规则核查至 2026-11-23）。

## 南京夜间公交小史

南京的夜间公交已有二十余年历史，大致经历以下几个阶段（日期均据公开报道，来源见本节末）：

- **2000 年 9 月 1 日 · 起步**：为促进夜间经济，南京首批开通 **18 条**夜间公交，普遍运营至次日凌晨 5 点，以 **8 字头**编号（801–823 等，如 801 路南京车站⇌夫子庙），此后陆续增开 819、820 及通往江北的盐葛线。夜公交自诞生起便陷入"公益与成本"的两难——凌晨 1 点后客流稀少，主城 20 条夜线长期亏损。
- **2014 年 8 月 20 日 · 更名 Y 字头**：夜间线路统一改用 **Y 字头**（"夜"的拼音首字母），803→Y3、808→Y8 等，沿用至今。Y 线多为通宵线，由江南公交（主城）与扬子公交（江北）分区域运营，后整合入南京公交集团各客运公司。
- **2020 年 · 疫情停运与恢复**：疫情前主城共有 37 条夜间线，疫情发生后全部停运；3 月 19 日率先恢复连接南京南站与南京西站的 **Y16 路**（谐音"歪石榴"），至 9 月 10 日全市 42 条夜间线全部恢复运营。
- **2024–2025 年 · 线网优化整合**：多次优化整合（如 2024-12-11 整合 Y1/Y9/Y10/Y19、2025-01-11 Y3 整合 Y15、2025-01-18 Y8 优化），Y6/Y9/Y14/Y15/Y18/Y19/Y20 等线路已撤销——这正是本模拟仅收录"现存"Y 线的原因。
- **2025 年 · 地铁末班守时公交**：为接驳地铁末班后的"最后一公里"，6 月 18 日首条"地铁末班守时公交"上线，对接地铁 S8 号线末班、服务六合方向（泰冯路地铁站），上座率一度达 95%；10 月 27 日开通 2 号线（迈皋桥东⇌月苑南路，5 站、10 分钟/班，对接地铁 1 号线末班）。本项目中的 **SS1/SS2** 即这两条守时公交。

> 参考来源：[南京20条夜公交全亏损（搜狐·2006-03-07）](https://m.sohu.com/20060307/n242166888.shtml)、[南京公交Y3路（百度百科）](https://baike.baidu.com/item/%E5%8D%97%E4%BA%AC%E5%85%AC%E4%BA%A4Y3%E8%B7%AF/19232623)、[夜游神看过来·坐"歪石榴"回家（江苏广电·2020-08-03）](http://news.jstv.com/a/20200803/0b01a9a3d157421fb340e30808518c8e.shtml)、[南京全市42条夜间公交线路全部恢复运营（南京本地宝·2020-09-22）](https://m.nj.bendibao.com/traffic/94801.shtm)、[南京又一条"地铁末班守时公交"来了（南京晨报·2025-10-29）](https://njcb.xhby.net/pc/con/202510/29/content_1497181.html)、[南京公交集团官网](https://www.njgongjiao.com/zhxw/8566)。

## 功能一览

| 功能 | 说明 |
| --- | --- |

| 站点实时弹窗 | 点击站点弹出途经线路与"下一班到站"，随模拟时间实时刷新；显示等待时间（"即将到站 / 1分钟 / X分钟"三档）与来车距本站/距起点的公里数 |
| 火车站式运行大屏 | 常驻右上角、可拖动可缩放的独立模块，按线号排序（主城数字序在前，溧水/高淳汉字前缀在后），实时列出所有在途车辆的线路、区间与状态 |
| 地铁闪灯图 | 点击任意车辆，页面顶端弹出该班车的闪灯式线路图：已过的站、当前站、下一站、终点站一目了然，随运行实时闪动 |
| 时段飞站 | 双龙街站 0:00–5:00 飞站通过不停车（走高架），模拟按每班车经过该站的时刻自动判定：飞站班车不停车、后续站点时刻相应提前，弹窗/大屏/闪灯图均以"飞站"样式区分 |

## 数据来源与处理

1. **线路采集**（`scripts/fetch_baidu.py` 等）：通过百度地图网页版接口（`qt=con/inf/bsl`）检索 Y1–Y45、守时公交及溧水/高淳夜间线，获取站点列表、发车时刻表与线路几何（502 路虽在检索词中，但属白天常规线，构建时剔除）。坐标经 **BD09MC → BD09LL → GCJ-02 → WGS-84** 逐级转换。
2. **网络构建**（`scripts/build_network.py`）：合并各来源为 `data/network.json`，按方向整理站点与路径。
3. **时刻表与运行时间**（`scripts/build_schedule.py`）：
   - 发车时刻：百度地图收录的**每方向固定时刻表**（权威来源），区间式时刻表按发车间隔展开。
   - 每班车从起点场站**独立发车**——夜间公交到终点即收车，下一班由最近场站发出，并非原车折返，因此运行时间与发车间隔解耦。
   - 逐站到达时刻由**分段限速旅速模型**推算（见下）。
   - 输出 `data/schedule.json`：每方向 `{deps, run, stopT, stopKm, frames, skip}`，frames 为沿路径的 `[分钟偏移, 纬度, 经度, 航向角, 沿程公里]` 关键帧，网页端在关键帧间插值。
4. **飞站规则**（`data/skip_stops.json`）：全网扫描 1081 个站名，含时段飞站标记的站点**仅 1 处**——双龙街(0时至5时不停靠)，出现在 Y21、Y27 往江宁方向；反向为双龙街(石林家乐家)，无标记。2024 年隧道施工、2026 年匝道封闭等**临时性**飞站公告不在建模范围（详见该文件内的证据链接）。

## 旅速模型与校准

南京公交实际限速：常规道路 40 km/h，高速/过江隧道区段 70 km/h；红绿灯与转弯进一步拉低旅速。模型按路径分段分类：

| 类别 | 判定 | 有效旅速 |
| --- | --- | --- |
| `reg` 常规道路 | 其余路段 | **24.11 km/h**（校准值） |
| `art` 江北大道地面辅路 | 距 SS1 走廊中心线 ≤0.45 km | **32.69 km/h**（校准值） |
| `fast` 高速/过江/长大站间距 | 相邻站直线距离 >2.5 km 的无站区段 | **60 km/h**（70 限速折减） |

另加：急转弯（>45°）每处 **+0.1 min**，停站 **0.6 min/站**。

校准（`scripts/calibrate_speed.py`，观测缓存 `data/calib_obs.json`，125 条）：

- `reg`：以百度路径规划给出的分段耗时为观测（其市区规划约 20 km/h + 停站），最小二乘拟合后市区段平均绝对误差 **≈94 秒**。
- `art`：以 SS1 公布全程 **70 分钟**（南京晨报 2025-06-20）为约束标定。
- `fast`：百度规划不区分道路等级，无法由其耗时校准，取限速折减的工程估计。

模型参数存于 `data/speed_model.json`，重算时刻表时自动读取。

## 本地运行与重建

网页本身零依赖构建：直接用浏览器打开 `realmap.html` 即可（底图瓦片与 Leaflet 来自 CDN，需联网）。

重建流程（Python 3，Windows 下建议 `PYTHONIOENCODING=utf-8`）：

```bash
# 1. 采集（已有 data/ 缓存时可跳过）
python scripts/fetch_baidu.py
python scripts/fetch_shoushi.py
python scripts/fetch_suburban.py

# 2. 构建线网
python scripts/build_network.py

# 3. 校准旅速模型（可选，读取 calib_obs.json 缓存）
python scripts/calibrate_speed.py

# 4. 生成运行时刻表
python scripts/build_schedule.py

# 5. 生成网页
python scripts/gen_realmap.py
```

回归测试（Node.js，无浏览器依赖，直接对网页内嵌脚本做沙箱求值）：

```bash
node tools/test_realmap.js   # 95 项断言：时刻表/插值/飞站/等待档位/大屏/闪灯图/说明弹窗/站点统一着色与缩放等
```

## 已知边界

- 模拟基于**固定时刻表 + 旅速模型**，不是实时 GPS 数据；实际路况、调度波动会造成偏差。
- 飞站仅建模站名中带时段标记的**常态化**规则（全网 1 处）；施工、跨年夜等临时跳站不建模。
- 溧水/高淳部分线路时刻表来源精度低于主城线路，已在数据中如实保留原始口径。
- 线路数据版权归百度地图等原提供方所有，本项目仅供学习交流与公共交通爱好者研究使用。

## 迭代历程

项目从 0 开始的完整迭代记录（按时间顺序）：

### 2026-11-20 · 从无到有

1. **数据采集**：通过百度地图网页版接口（`qt=con/inf/bsl`）检索 Y1–Y45 夜间线与 2 条地铁末班守时公交，逐方向获取站点列表、发车时刻表与线路几何（502 路经核查为白天常规线，夜间服务由守时公交1号线承担，故剔除）；坐标经 BD09MC → BD09LL → GCJ-02 → WGS-84 逐级转换。两个方向站点分别采集，单向站如实保留。
2. **初版双图**：编写代码绘制地铁运营图风格的抽象夜间公交运营全图，同时在 Leaflet 真实地图上叠加线路与站点。
3. **抽象图重绘**：按真实地铁运营图的规范重绘——线条严格横平竖直/45°、简化走向，不追求百分百还原精确几何（精确走向由真实底图承担）。
4. **运行模拟 v1**：采集每条线路每方向的发车时刻，在真实地图上实现按时间的运行模拟：播放器式自动播放/暂停、进度条任意拖动、手动输入时间跳转；公交小车图标自绘，随位置与航向旋转。
5. **面板 bug 修复**：修复右侧线路栏首末站被显示为同一站的问题（点击站点弹窗显示正常，仅面板渲染有误）。
6. **旅速模型重构与校准**：核实南京公交实际限速（常规道路 40 km/h、高速与过江隧道 70 km/h）与红绿灯/转弯折减；核实夜间公交到终点即收车、下一班由最近场站独立发出（并非原车折返），据此将运行时间与发车间隔解耦。路径按 reg/art/fast 三类分段建模，用百度路径规划分段耗时（125 条观测）与 SS1 公布全程 70 分钟校准；"车来了"到站预测接口经尝试不可用，弃用。

7. **交互改版 + 远郊扩网**：弃用抽象示意图页（移入 `deprecated/`），仅保留真实底图；速度选择改为指针式速度表盘并新增 20/30 分钟/秒档位；站点弹窗改为随模拟时间实时刷新；新增火车站大屏式运行展示窗；调研并接入溧水、高淳夜间公交，线网扩至 43 线/86 向/1080 站。

### 2026-11-24 · 细节修复

10. **弹窗拖图修复**：修复站点弹窗打开时拖动地图被强制拉回的问题——Leaflet 默认 `autoPan` 会在每次拖动结束与弹窗内容刷新时重新平移地图以完整显示弹窗；现关闭 `autoPan`，改为仅在弹窗打开时一次性避让屏幕边缘，拖动地图与实时刷新均不再拉回视野。
